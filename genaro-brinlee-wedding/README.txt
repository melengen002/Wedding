GENARO & BRINLEE — WEDDING WEBSITE

FILES
-----
index.html  — website structure and all copy
style.css   — complete design and responsive/mobile styles
script.js   — bilingual mode, countdown, RSVP demo, animation, music
images/     — put your photos here
music/      — put your licensed wedding-song.mp3 here

HOW TO OPEN IT
--------------
1. Keep all files in the same folder structure.
2. Double-click index.html.
3. It will open in Safari/Chrome/Edge.

ADDING YOUR PHOTOS
------------------
Put your own JPG files inside the images folder with these exact names:

hero.jpg
couple-1.jpg
couple-2.jpg
couple-3.jpg
couple-4.jpg
couple-5.jpg

You do NOT have to edit the HTML if you keep those filenames.

RSVP IMPORTANT NOTE
-------------------
The current RSVP is a working DEMO. It saves submissions to localStorage in the
guest's own browser. That means YOU will not receive their RSVP yet.

Before publishing, connect the form to a real database/form endpoint such as
Formspree, Google Apps Script + Google Sheets, Supabase, Firebase, or your own
backend.

REGISTRY
--------
The registry buttons are intentionally fake placeholders. Search "REGISTRY" in
index.html and replace each href="#" with your real registry links.

MUSIC
-----
Create a folder named "music" beside the other files and add a song you have
permission to use named:

wedding-song.mp3

The music does NOT autoplay. Browsers generally require the visitor to interact
with the page before audio can play.

BILINGUAL COPY
--------------
Most translated copy is in the "translations" object at the top of script.js.
Edit the English under "en" and Spanish under "es".

PUBLISHING
----------
This is a static website and can be hosted on services such as GitHub Pages,
Netlify, Vercel, or a traditional web host. A custom domain can be connected
after hosting.

Enjoy building it — and replace the fictional details before sending it to Grandma.
